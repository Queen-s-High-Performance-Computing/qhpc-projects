Small educational examples supporting QHPC proposals. Project implementations live in separate QHPC GitHub organization repositories.

- [vLLM environment setup](vllm-setup/README.md): a Slurm installation job using the CAC module Python and a prebuilt llguidance wheel.

Give each sample a directory with a README covering its purpose, dependencies, run instructions, expected output, and correctness check. Link it here and from any relevant proposal. See [contribution guidelines](../CONTRIBUTING.md).
