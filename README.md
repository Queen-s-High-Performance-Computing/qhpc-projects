# QHPC Projects

Project proposals, samples, and reference material for QHPC members. Use this repository to explore ideas, assess their feasibility, and prepare to build them together. Projects focus on learning and preparation for SC27, ISC, and other supercomputing competitions, including benchmarking, scientific applications, and useful software.

The repository is currently in the proposal stage; no project ideas have been added yet.

## Projects and resources

| Area | What you can explore |
| --- | --- |
| [Proposals](proposals/README.md) | Project ideas, scope, feasibility, and open questions |
| [Samples](samples/README.md) | Small examples and experiments |
| [Resources](resources/README.md) | Papers, existing repositories, and other inspiration |

## Getting started

Browse the areas above, or start an idea from the [proposal template](proposals/template.md). Each idea gets its own directory under `proposals/`. Project implementations live in their own repositories in the QHPC GitHub organization.
